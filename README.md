A momentum-aware forecaster for pump.fun's newest Solana coins: it extrapolates each coin's market-cap trajectory from the full snapshot history, spreads honest probabilities over the plausible top 5 at each place (leaving room for coins not yet born), and models each place's market cap in log space.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
